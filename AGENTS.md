# Coordinación de Vigía

1. Antes de editar, consulta [EPIC.md en la rama por defecto](https://github.com/marcmarti9/Hack-2026-27/blob/main/EPIC.md). Haz `git fetch origin` y lee `git show origin/main:EPIC.md` para ver el estado vigente desde cualquier rama.
2. Registra en el épico qué parte vas a tocar si tu trabajo puede coincidir con el de otra sesión. Revisa los archivos y ramas que ya tienen responsable antes de editar.
3. Al terminar, añade una entrada con tu sesión, rama o PR, lo que cambiaste, las pruebas ejecutadas, los bloqueos y el siguiente paso. Actualiza el archivo de `main` mediante un commit de coordinación o un PR breve si la rama está protegida.
4. Incorpora las actualizaciones concurrentes antes de publicar. Conserva las entradas anteriores y deja credenciales, logs sensibles y rutas privadas fuera del repositorio.
